开始使用

安装

下载并安装 Drora 桌面应用，开始体验 Drora Agent 驱动的端到端开发工作流。全程约 2 分钟：下载安装包 → 完成安装 → 首次启动。

  1. 下载安装包
  2. 完成安装
  3. 首次启动

下载

立即下载 Drora：桌面安装包与 CLI 单文件均发布在 Releases。

文件 说明
Drora-<版本>-win-x64.exe / win-arm64.exe Windows 桌面应用安装包（NSIS）
Drora-<版本>-mac-arm64.dmg / mac-x64.dmg（及 .zip） macOS 桌面应用
drora-windows-x64.exe / drora-darwin-arm64 / drora-linux-x64 Agent CLI 单文件，须在终端中运行（双击会闪退）

支持 macOS（Apple Silicon / Intel）与 Windows（x64 / ARM64）。暂不提供 Linux 桌面安装包：Linux 用户可先使用 CLI 单文件，或从源码构建桌面应用。

安装步骤

macOS

  1. 打开下载的 Drora.dmg 安装镜像。
  2. 将 Drora.app 拖动到 Applications 文件夹。
  3. 在启动台中找到 Drora 并启动。

Windows

  1. 下载 Drora 安装程序。
  2. 双击运行，按照安装向导完成安装。
  3. 从开始菜单或桌面快捷方式启动 Drora。

Agent CLI

单文件可执行，放到 PATH 目录或直接以路径运行；必须在终端中启动，双击会闪退。首次使用先执行 drora login完成浏览器授权，即可开始提问。

安装包未做签名：Windows 首次运行请在 SmartScreen 提示时选择「更多信息 → 仍要运行」；macOS 首次打开若被拦截，可在「系统设置 → 隐私与安全性」中放行，或执行 sudo xattr -rd com.apple.quarantine /Applications/Drora.app。

首次启动

首次启动会进入「首次启动设置」页面，完成后在左下角点击「连接使用」进入登录页面：

  1. 点击「开始使用 Drora」直接进入。如需迁移历史数据，可选择「数据迁移向导」：目前支持导入 Claude Code 的对话记录，不支持其他工具；也可以先跳过，稍后在设置中继续迁移。
  2. 进入后选择一个项目目录作为工作区。
  3. 在对话框输入一句简单指令，比如让 Agent「列出当前目录的文件」，确认响应正常。

如果还没有配置模型，点击左下角「连接使用」进入登录页面，引导你「连接 Z.ai」「连接 BigModel」或「使用 API Key」完成接入，详见 连接模型。

校验与更新

所有产物均由 GitHub Actions 从源码构建， SHA256SUMS.txt提供校验和。

桌面应用内置自动更新（latest 通道），也可以在「帮助 → 检查更新」手动检查；随时可到 Releases 页下载新版本覆盖安装。

CLI 单文件没有自更新：重新下载新版本的 drora-<os>-<arch>替换旧文件即可。

网络代理

如果你的网络需要走代理才能访问模型服务，在「设置 → 常规」里可以配置。这里有三个字段，填完点保存，需要重启应用才生效。

「HTTP 代理」：填入代理地址，例如 http://127.0.0.1:7890。

留空不等于跟随系统。这个字段为空时 Drora 直连，不会读取 HTTP_PROXY 等系统环境变量。这一点和很多命令行工具的默认行为相反，如果你发现终端里能联网而 Drora 不行，多半就是这个原因。

配置后，模型请求、MCP 服务、Agent 执行的命令工具以及应用界面的网络请求都会走这个代理。

「不使用代理的地址」：不想走代理的地址，用英文逗号分隔，例如：

localhost,127.0.0.1,::1,.example.com,*.corp.com

主机名、.example.com 这样的域名后缀、*.corp.com 通配写法都支持，需要时还能带上端口。

「自定义证书」：填 PEM 格式根证书的本地文件路径。企业内网如果用了会解密 HTTPS 的安全网关，它签发的证书默认不被信任，把对应的根证书填在这里即可。注意这「不是」跳过证书校验——Drora 只放行证书链里确实包含这张根证书的连接，其余照常校验。

代理设置修改后需重启应用生效。CLI 侧可在用户配置文件 ~/.drora/cli/config.json 中设置 network.httpProxy、 network.noProxy、 network.caCertFile，语义相同。

Windows 专属设置

「选择命令行环境」：在「设置 → 常规 → 终端」里可以指定 Agent 执行命令时用哪个 shell，可选「自动选择」「CMD」和「Git Bash」（检测到已安装时才出现）。默认是自动，优先用 Git Bash，找不到就回退到 cmd.exe。改动只对新建会话生效。

「关闭窗口时隐藏到托盘」：Windows 上默认开启，点窗口的关闭按钮不会退出应用，而是收进系统托盘继续运行，定时任务和闲时任务也因此能在后台照常推进。托盘图标右键有打开 Drora、新建任务、打开工作区、检查更新、退出等菜单项，左键点击可以把窗口叫回来。想让关闭按钮直接退出，在设置里关掉「关闭窗口时隐藏到托盘」即可。这个开关只有 Windows 有。

故障排查

macOS 提示「Drora 已损坏，无法打开」

这是未签名安装包被 Gatekeeper 隔离的正常表现，在终端执行以下命令解除隔离属性后重新打开：

sudo xattr -rd com.apple.quarantine /Applications/Drora.app

Windows 安装时被防火墙 / 杀软拦截

安装包未做代码签名，SmartScreen 拦截属预期行为：在提示时选择「更多信息 → 仍要运行」；安全软件拦截时，暂时关闭实时防护或将安装目录加入白名单后重试。

CLI 提示没有执行权限

macOS / Linux 下载的单文件需要执行权限： chmod +x drora-* 后再运行。
