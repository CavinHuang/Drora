快捷键表

这里保留的是 Drora 桌面端最常用、最值得记住的快捷键。我们优先整理和任务流、聊天输入、日常高频操作直接相关的内容，不把系统原生菜单里的低频项全部堆上来。下表中 Windows / Linux 列使用 Ctrl，macOS 列使用 Command；全部快捷键都可以在「设置 → 键盘快捷键」里查看和修改。

全局操作

Windows / Linux macOS 功能
Ctrl+N Command+N 新建任务
Ctrl+B Command+B 切换侧栏
Ctrl+J Command+J 切换终端面板
Ctrl+Alt+B Option+Command+B 切换右侧面板
Ctrl+K / Ctrl+Shift+P Command+K / Command+Shift+P 打开命令中心
Ctrl+F Command+F 任务内查找
Ctrl+[ Command+[ 后退到上一个任务或工作区
Ctrl+] Command+] 前进到下一个任务或工作区
Ctrl+Shift+[ Command+Shift+[ 切换到上一个任务
Ctrl+Shift+] Command+Shift+] 切换到下一个任务
Ctrl+, Command+, 打开设置
Ctrl+Shift+L Command+Shift+L 切换深色 / 浅色主题
Ctrl+Shift+U Command+Shift+U 切换编程 / 办公模式
Ctrl+Shift+O Command+Shift+O 显示 / 隐藏新用户引导

输入框与工具条

Windows / Linux macOS 功能
Ctrl+M Ctrl+M 打开模型菜单
Ctrl+Shift+M Ctrl+Shift+M 切换执行模式（聊天输入框聚焦时循环切换）
Ctrl+T Ctrl+T 切换思考深度
↑ / ↓ ↑ / ↓ 在 Slash 或 Mention 面板中切换选项
Enter / Tab Enter / Tab 选中当前高亮项
Esc Esc 关闭当前面板或菜单
Enter Enter 发送消息
Shift+Enter Shift+Enter 输入框内换行

模型菜单、执行模式与思考深度三组工具条快捷键使用显式 Ctrl 修饰，在 macOS 上同样是 Ctrl 键。输入框内还支持 @、#、/、$ 触发符唤起补全面板，用上下键与 Enter 选中候选。

桌面菜单

Windows / Linux macOS 功能
Ctrl+O Command+O 打开工作区
Ctrl+W Command+W 关闭当前上下文
Ctrl+= Command+= 放大
Ctrl+- Command+- 缩小
Ctrl+0 Command+0 恢复缩放

自定义快捷键

打开「设置 → 键盘快捷键」，可以搜索命令、录制新的组合键、清除绑定或一键恢复全部默认。绑定同时用于持久化、界面匹配与桌面菜单加速键；录制时中文输入法组合态与长按重复会被自动忽略。

执行模式、权限确认等工作流的完整说明见 安全操作确认 与 Drora Agent 。
