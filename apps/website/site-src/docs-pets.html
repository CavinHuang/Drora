核心功能

桌面宠物

桌面宠物汇总已打开工作区的任务活动，包括后台标签页和其他窗口。可选择紫罗兰小猫、夜墨、雪铃、杏桃，或导入兼容 Codex 的自定义宠物。

显示与交互

在设置的「桌面宠物」中启用并调整大小。点击宠物或徽标查看任务活动，点击任务行回到原窗口；拖动宠物移动位置，按住 Alt 松开可吸附到屏幕边缘。徽标可以拖到四角，右键菜单可以切换或隐藏宠物。

导入与创建

设置支持导入整个 pets 文件夹、单只宠物文件夹或 PNG/WebP 精灵图，也支持刷新、导出和删除自定义宠物。兼容 pet.json（v1/v2）及旧 avatar.json，导入会复制素材，不修改原文件。所有宠物使用同一套 Codex 格式和播放器；v2 精灵图支持 16 方向鼠标跟随，内置宠物也可导出为标准包。

「创建宠物」会打开带有素材规格和保存目录的新任务草稿，由你补充角色想法并发送。选中 v1 自定义宠物时，还可以通过「升级到 v2」生成保留原角色的新版素材。生成能力取决于该任务可用的图片工具；完成后回到设置刷新并选择宠物。桌面浮窗不提供快速聊天或语音。
