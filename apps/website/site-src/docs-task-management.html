核心功能

任务与文件管理

随着任务越积越多，左侧边栏提供了几个高频管理能力： 任务视图 让你按分组、项目或时间线组织任务列表， 工作区文件树 让你不离开 Drora 就能浏览文件、查看变更并把文件引用进对话。

任务视图

左侧任务栏顶部的视图菜单提供三种组织方式，可以随时切换。

  • 分组 ：按自定义分组归类任务，适合按主题或优先级整理。
  • 项目 ：任务跟着项目走，每个项目下平铺它的任务。
  • 时间线 ：按时间倒序排列，找最近做过的事最快。

视图菜单旁边还有三个常用入口：

  • 排序方式 ：在视图菜单里选择，按创建时间或更新时间排列任务。
  • 搜索 ：点击放大镜图标，按关键词筛选任务列表，归档列表内也支持搜索。
  • 归档 ：点击归档图标进入归档列表。已完成、无未读、未置顶且超过保留期的任务会进入自动归档候选（保留期可设 3 / 7 / 14 / 30 天，可在设置中调整）；列表里每条任务右侧有两个按钮，分别用来取消归档（恢复回任务列表）和删除。删除任务会连同它的会话快照与 checkpoint 一起清理。

任务分组

切换到分组视图，即可按自定义分组组织任务。

创建与管理分组

  1. 点击「新建分组」，输入分组名称
  2. 点击分组标题右侧的颜色点，可在 7 种颜色（灰 / 红 / 橙 / 黄 / 绿 / 蓝 / 紫）中选择，用颜色区分项目或优先级
  3. 单击分组标题可随时重命名
  4. 右键分组可选择「取消分组并删除」——只删除分组本身，组内任务会保留并移出分组

整理任务

  • 拖拽 ：直接把任务拖进目标分组，也可以在组内拖拽排序、拖动分组标题调整分组顺序。
  • 右键菜单 ：在任务上右键选择「移动到分组 / 移出分组」，不方便拖拽时同样高效。
  • 移动到顶部 ：组内任务较多时，右键选择「移动到顶部」比一路拖上去快得多。
  • 折叠与展开 ：点击分组标题左侧的三角形折叠单个分组，或用列表顶部按钮全部展开 / 收起。

命令中心

按 Ctrl/Command+K （或 Ctrl/Command+Shift+P ）打开命令中心：新对话、打开文件夹、搜索文件、切换主题、打开设置等常用操作都能在一个面板里直接执行，旁边标注了对应的快捷键，熟悉之后基本不用碰鼠标。结果可按「全部 / 操作 / 任务 / 文件」筛选。全部快捷键见 快捷键表 。

工作区文件树

点击工作区卡片右侧的文件树图标（查看文件），左侧边栏会切换为当前工作区的文件树；点击顶部「返回任务」即可切回任务列表。

浏览与搜索

  • 搜索文件 ：顶部搜索框支持按文件名或路径实时筛选。
  • 仅显示变更文件 ：一键过滤出有 Git 变更的文件，代码评审或提交前检查特别好用。
  • Git 状态标识 ：文件右侧会显示 Git 状态标记（新增 / 修改 / 删除 / 重命名），目录上会聚合显示内部变更状态点。

打开与引用

  • 单击文件即可在右侧打开预览；右键菜单提供「打开方式」「添加到聊天」「复制路径」「在资源管理器中打开」等操作，本地 HTML 文件还能「用内置浏览器打开」。
  • 拖拽到对话框 ：把文件直接拖进对话输入框，自动插入文件引用，让 Agent 围绕该文件工作。
「仅显示变更文件」+「添加到聊天」组合使用，可以快速把本次改动的文件喂给 Agent 做自查或生成提交说明。

附件也支持拖放与粘贴的方式加入输入区，详见 Drora Agent 。

Git 图谱

工作区顶部的分支切换器下拉里还有一个 Git 图谱 入口，打开后是一张只读的提交历史图：分支并排画出，合并发生在哪里一目了然，适合理清「这个分支是从哪儿分出去的」「这两条线什么时候合的」。顶部会汇总提交数、泳道数、合并与引用数量。

点击某个提交会在旁边显示它的标题、完整哈希、作者、日期和父提交。默认先加载最近的一批，点「加载更多提交」继续往前翻。

它只负责看： 不能在图里切换分支，也不能查看具体改动内容 。切换分支、新建分支在同一个下拉菜单的上半部分——如果切换时有未提交的改动，Drora 会提示你先提交，也可以选择提交后自动继续切换。
