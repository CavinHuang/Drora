隐私说明

Drora 本地优先，数据保存在你自己的设备上。

Drora 本地优先：会话与配置数据保存在你自己的设备上。以下是数据存储与网络行为的如实说明。

本地存储

应用的会话、设置、缓存与任务记录保存在本机应用数据目录；CLI 会话数据库位于 ~/.drora/cli/db/；可用环境变量 DRORA_DATA_BASE_DIR重定向数据位置，详见 README 配置节。

网络请求

模型请求会发送到你配置的模型服务端点（含请求中的认证信息）；启用自动更新后会访问 GitHub Releases 检查新版本；插件市场、帮助内容等功能会按需访问相应服务。完整的对外请求矩阵以 NOTICE.md第二节为准。

凭据与反馈附件

凭据保存在本机，不写入提交与日志。提交 Issue 或反馈附件前，请自行检查内容并去除令牌、密钥等敏感信息。

关于本网站

本网站为纯静态页面：不嵌入统计、追踪或第三方脚本，不设置 Cookie。
