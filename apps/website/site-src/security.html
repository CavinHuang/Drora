提交漏洞

报告 Drora 的安全与隐私问题，帮助我们让项目更安全。

报告渠道

Drora 是社区维护的开源项目。发现安全或隐私问题时，请按敏感程度选择渠道：

  • GitHub 私密漏洞报告（推荐）：敏感漏洞请通过 私密安全咨询提交，仅维护者可见。
  • GitHub Issues：非敏感的加固建议与配置问题，可到 Issues公开讨论。
在漏洞修复发布前，请勿在公开渠道描述可被直接利用的细节或发布利用代码。

测试范围

欢迎研究本仓库实际发布的形态：

形态说明
桌面客户端macOS / Windows 安装包（Releases 发布）
Agent CLI单文件可执行（drora-<os>-<arch>）
Web / Server本地与自托管部署（dev:web 或发行包）

第三方依赖的安全问题，除报告本仓外也欢迎同步告知上游项目。

处理流程

  1. 提交报告：附复现步骤、影响评估与环境版本。
  2. 确认与评估：维护者复现问题并评定严重程度。
  3. 修复与发布：严重问题优先修复并发版。
  4. 披露与致谢：修复发布后公开披露，并（征得同意后）致谢报告者。

关于奖励

本项目为社区开源项目，暂无漏洞赏金计划；有效的安全报告是对项目最直接的帮助，我们会在披露中如实致谢。

用户安全建议

Agent 具备文件、终端与网络操作能力，会以你的账号权限真实执行。建议限制运行账号与网络权限、在重要操作前备份，并阅读 NOTICE.md.
