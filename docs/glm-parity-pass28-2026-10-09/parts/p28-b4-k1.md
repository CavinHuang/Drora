### K1-02 `/model main` 语义差（P2）

- 真值：命令中心 handler GQo（@14717700 附近）把**原始 args 字符串**直接传 `app.setModel(e)`；bootstrap `setModel`（@13868700+）`typeof l=="string"?g$o(registry,l,configuredDefaultModelSelection,{allowMissingReasoning:!0})`；`g$o` → `i9a`：`t==="main"?n`（即**配置默认选择**，含档位；无 normalize）。`configuredDefaultModelSelection` 来自 protocol bootstrap 配置（Wec @14679300），非会话当前选择。无任何 "main requires" 错误串（全 bundle grep 无）。
- 我方：`packages/cli/src/command-center/handlers/model.ts:38-44` 在 handler 层截胡 `main`：`mainRef = app.getCurrentModelOption?.()?.ref`（**会话当前模型**，ref 无 options），经 selectedRef 通道让 `resolveTuiModelSelection` 取目录默认档；`:41-42` 当前无会话选择时 `throw new Error("main requires an active model selection. Use /model provider/model.")`。app 层字符串通道虽同形移植（`bootstrap/src/app/session-facade.ts:458-464` resolveRegistryOwnedSelection + configuredDefaultModelSelection），但 handler 永不传字符串，实际走选我方截胡语义。
- 判定：会话选择≠配置默认时两者结果不同（真值回到配置默认模型；我方留在当前模型）；新会话未做选择时真值可用、我方报错。P2。
