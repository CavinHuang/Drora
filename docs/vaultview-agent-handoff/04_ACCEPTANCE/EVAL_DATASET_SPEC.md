# 真实中文知识检索评测数据集规范

## 目的
分离召回错误、重排错误、证据不足和生成错误；Jev 自身评分不得作为真值。所有内容使用用户授权的脱敏资料或合成语料，绝不上传真实私密 Vault。

## 标注
- 每条 Query：ID、模糊描述、用户意图 FIND/ANSWER/COMPARE、允许源/文件夹/时间硬过滤、是否真实存在答案。
- 标记最多若干正确 article IDs、可支持观点的 chunk IDs、锚点、反证/冲突来源、可接受的回答要点。
- 覆盖已知标题、忘记标题只记得观点、同义词/缩写、中英混合、剪藏噪音、时间线索、近似多篇、原文不存在和源已过期。
- 双人独立标注不一致时复核仲裁；训练/调参与最终测试分集；保留评测版本。

## 指标
| 指标 | 解读 |
|---|---|
| Recall@30 | 正确文章是否进入召回短名单（Jev 无法挽回未召回文章） |
| Hit@1 / Hit@5 / MRR | 文章级准确排序 |
| Evidence Precision | 候选片段直接支持用户所记观点的比例 |
| No-answer FP | 无答案时错误宣布找到的比例 |
| Citation Support | 答案事实断言受到真实当前源内容支持的比例 |
| P50/P95 / Cost | 总延迟及远端费用 |

## 对照
至少对比 Lexical、Lexical+Semantic、Hybrid+Jev、Hybrid+专业 reranker；每组使用同一个 Query/Scope 和稳定的候选集合，标注模型、阈值、硬件与外发许可。

建议初期 100–200 条中文样例（仅为试点规模），数据不足时不声称有效果。
