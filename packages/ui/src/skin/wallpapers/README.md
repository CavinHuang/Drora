# Built-in skin wallpapers

These six wallpapers were created with the built-in `image_gen` tool on 2026-09-27, then converted to WebP with Pillow at quality 80. Each image is 1672 × 941 pixels. Keep the generated art in this directory so the shared UI stylesheet can bundle it for Desktop and Web.

## Prompts

### Ocean

> Use case: stylized-concept. Asset type: built-in wallpaper for a calm, dense AI coding workspace, wide desktop composition around 16:9. Create a refined atmospheric illustration of an ocean coast seen from a distant elevated viewpoint: soft rolling sea, a few layered headlands fading into mist, subtle paper-like grain. Muted blue, teal, slate and pale sea-glass palette matching an Ocean skin. Keep the middle 70% of the composition visually quiet and low contrast so translucent app panels and text remain readable; put slightly richer shapes toward the far edges. Professional editorial quality, soft diffuse daylight, gentle depth, no people, no buildings, no icons, no text, no logos, no watermark, no hard horizon stripe, no high-frequency details.
