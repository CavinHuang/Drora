版本发布与更新

Drora 各版本的更新说明与桌面端下载。

新功能

  • macOS 应用内自动更新链路闭环：CI 自签名接入，安装失败自动恢复。

问题修复

  • 手机远控云中继生产路径修复：WebSocket 构造器回退到 ws 包。
  • 修复工作区壁纸穿透透明皮肤面板的层级问题。

新功能

  • 皮肤中心内置多套插画预设壁纸。
  • 皮肤滑块与预设选中态视觉打磨，对齐设计规范。

新功能

  • 手机远控接入 relay 云中继：跨网络远控与局域网直连并存。
  • rpc-frame 透明桥：手机页面可直接操控桌面任务。

维护

  • CI 打包稳定性：打包复制竞速退避重试，Windows 构建关闭实时监控。

新功能

  • 皮肤中心上线：自定义壁纸、面板透明度与强调色。
  • 手机远控弹层双栏布局与连接状态卡。

问题修复

  • 桌宠气泡悬停位置修正：顶部居中、限宽与换行优化。

新功能

  • 手机远控二轮打磨：六态连接状态机、应用启动自动恢复、窗口关闭即停服。

新功能

  • macOS Computer Use（屏幕操作助手）对齐上游 ZCode 3.14.3：独立 Helper 随包分发与信任链引导。
  • 「开始计划」接入验证码校验，修复 3007 鉴权失败。
  • 桌宠气泡内容与拖拽布局通道。

变更

  • Obsidian 插件 MCP 面移除，改为 hooks 直连（SessionStart / PermissionRequest / UserPromptSubmit）。

新功能

  • 对齐上游 ZCode 3.14.3 全量官方插件（含 Computer Use 0.6.3 整代迁移）。
  • 输出风格系统（outputStyle）功能域落地。
  • 市场个人数据对齐：内置源与 CDN 图标索引。
  • server 远程五项收口：共享门禁、资源释放、快照与工作区界面。

新功能

  • 首个公开构建：Windows / macOS 桌面安装包与 Agent CLI 单文件可执行。
  • 手机远程配对协议与服务端基础。

谢谢每一位试用与反馈的伙伴。
