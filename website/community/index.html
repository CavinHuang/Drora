参与贡献

欢迎为 Drora 贡献代码与文档，推荐流程：

  1. 先开 Issue 描述问题或方案，避免重复工作。
  2. Fork 仓库并从 main 拉取分支开发。
  3. 遵循仓库 AGENTS.md 的规范（spec 先行、类型与 lint 检查）。
  4. 提交 Pull Request 并通过持续集成。

社区氛围

请保持友善与尊重：对新手多些耐心，对不同技术方案就事论事。让每个人都愿意提问，社区才有价值。
