智能体开发环境工具

Drora 不只是一个 Agent 输入框，也是一套面向真实开发任务的智能体开发环境（ADE，Agent Development Environment）：你可以在一个窗口里管理任务、按项目组织对话、进入远程开发环境、预览文件，并在终端面板里跑构建与测试。

工作区与任务列表

左侧边栏跟随当前工作区展示任务列表，顶部提供新建任务、搜索与视图切换。任务视图支持分组、项目、时间线三种组织方式，非分组视图下还能按创建时间或更新时间排序。每一行会显示任务标题、相对时间与状态（运行中、等待确认等）；任务产生改动后还会显示该任务的 +/- 变更行数，方便快速判断 Agent 在哪些任务里改了多少内容。

归档任务

不再活跃的任务可以归档，从主列表里收起来。归档列表里每一行同样显示标题、相对时间、变更统计和所属工作区，并提供恢复和删除操作；确认无用后也可以删除所有归档任务。删除任务会连同它的会话快照与 checkpoint 一起清理，需要回顾旧任务时先恢复再操作。

命令中心

按 Ctrl/Command+K （或 Ctrl/Command+Shift+P ）打开命令中心，在一个面板里快速触达常用操作和导航。它同时覆盖操作、任务和文件三类搜索：新建对话、打开文件夹、搜索文件、打开设置、切换主题、切换终端等都能直接执行。全部快捷键见 快捷键表 。

远程开发与远程接入

在「打开工作区」页面可以选择本地文件夹，也可以进入远程连接：通过 SSH 远程主机、WSL（Windows Linux 子系统）、Docker 本地容器或已运行的 Drora Server 打开远程工作区，让 Agent 在真实运行环境中读取文件、执行命令和推进任务，连接过程与日志在窗口内可见。

人不在电脑前时的操作入口是手机远控：手机浏览器直连桌面已有 Host，复用同一会话运行时，断线可恢复回放。详见 远程开发 与 手机远控 。

文件与内容预览

点击文件树里的文件会在预览面板打开，除了代码，几类常见格式也能直接看：

  • PDF：只读查看，适合看需求文档与设计稿，不提供编辑和批注。
  • Mermaid 图表：回复里的 mermaid 代码块直接渲染成图，可放大查看。
  • 图片：Markdown 图片可以点开预览，连续多张会自动排成图集翻看。
  • 表格：Markdown 表格自带工具栏，可以复制成 Markdown、下载成 CSV，或打开更大的预览窗口，很宽的表格还能展开滚动区域。

终端与搜索

按 Ctrl/Command+J 可以打开终端面板，在同一个工作区里运行构建、测试、启动服务、查看日志，再把结果继续交给 Agent 分析。

大仓库里搜东西容易慢，而且结果取决于本机装的是哪个版本的 find 和 grep。「设置 → 增强 Find 和 Grep」开启后，新建会话会使用增强的搜索工具，各台机器上的表现更一致；当前会话保持现有设置，Windows 的 Find 保持不变。
