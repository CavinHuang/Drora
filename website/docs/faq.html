常见问题

这里汇总安装与更新、模型连接、Agent 行为与数据迁移的高频问题。

安装与更新

安装时提示「已损坏」或 SmartScreen 拦截？

社区构建未做签名：Windows 选择「更多信息 → 仍要运行」；macOS 在「系统设置 → 隐私与安全性」放行，或执行 sudo xattr -rd com.apple.quarantine /Applications/Drora.app。

有 Linux 桌面版吗？

暂未提供 Linux 预编译安装包；Linux 用户可先使用 CLI 单文件（ drora-linux-x64 ），或从源码 pnpm bundle:desktop -- --os linux自行构建。

如何更新？

桌面应用内置自动更新（latest 通道），也可以随时到 Releases 页下载新版本覆盖安装。

模型与连接

终端里已经配置好 GLM 环境，应用里还要再配吗？

需要。模型连接在应用内完成：桌面端在「设置」中登录 Z.ai 账号，或在「模型供应商」里手动添加 Base URL 与 API Key；CLI 执行 drora login 完成浏览器授权。终端环境变量与这些入口相互独立，见 连接模型。

MCP 服务器连接失败怎么办？

在「设置 → MCP 服务器」查看该服务器的状态与失败原因：配置无效就检查字段填写；网络不可达就检查网络与代理；协议协商失败可在编辑服务器时把协议版本切换为「兼容旧版」；要求授权的服务重新「打开授权」。详见 MCP 与插件。

Agent 行为

为什么上下文没用满就开始自动压缩？

自动压缩不会等窗口填满：触发点按「上下文窗口 − 输出预留 − 安全缓冲」计算，要为模型输出留出空间（输出预留默认 32K、安全缓冲 13K）；没有单独配置时，窗口默认按 200K 计算。窗口越小触发越早，属正常现象。模型实际的上下文窗口可在「设置 → 模型供应商」中按模型编辑，填准后压缩时机即会后移。

指令发错了、文件被改坏了怎么办？

不用重开任务：悬停自己发送过的消息点「编辑」，改写后重发；需要回退文件时用「对话 + 文件重置」；每轮回复下方的文件变更摘要支持「撤销 / 重新应用」。详见 会话与编辑历史。

数据与迁移

换电脑，要复制哪些配置文件？

把下面这些复制到新机器的相同位置，即可带走绝大部分配置：

路径 带走什么
~/.drora/cli/config.json MCP 服务器、权限默认值、插件与技能开关、Hooks 等 Agent 配置
~/.drora/AGENTS.md 全局规则
~/.drora/skills/ 用户级技能
<项目>/.drora/ 项目级配置，随仓库走，不用单独复制

有两个文件不要复制：~/.drora/v2/credentials.json（登录凭据为加密存储，在新机器重新登录即可）与 ~/.drora/v2/telemetry-state.json（含设备标识，不应跨机器共用）。会话数据（~/.drora/cli/db/）可按需搬运。

在哪里查看版本号？

桌面端在菜单「帮助 → 关于 Drora」查看当前版本，「帮助 → 检查更新」会提示新版本；CLI 在终端执行 drora --version。
