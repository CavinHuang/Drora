开始使用

欢迎使用 Drora

Drora 是一个开源的 AI 编程工作台：桌面应用、浏览器界面和终端 Agent 三种形态共享同一运行时。它把长上下文、长程任务与 Agentic 编程能力转化为稳定可用的桌面体验，覆盖规划、编码、审查与迭代的完整流程。

Drora 基于上游 ZCode 开源复刻并持续跟进，由社区维护。功能范围、维护规则与许可说明见 NOTICE.md。

安装

无需从源码构建，直接在 Releases：

文件 说明
Drora-<版本>-win-x64.exe / win-arm64.exe Windows 桌面应用安装包（NSIS）
Drora-<版本>-mac-arm64.dmg / mac-x64.dmg macOS 桌面应用
drora-windows-x64.exe / drora-darwin-arm64 / drora-linux-x64 Agent CLI 单文件，须在终端中运行（双击会闪退）
安装包未做签名：Windows 首次运行请在 SmartScreen 提示时选择「更多信息 → 仍要运行」；macOS 首次打开若被拦截，可在「系统设置 → 隐私与安全性」中放行，或执行 sudo xattr -rd com.apple.quarantine /Applications/Drora.app。

所有产物均由 GitHub Actions 从源码构建， SHA256SUMS.txt提供校验和；桌面应用内置自动更新（latest 通道）。

连接模型

Drora 面向 GLM 系列模型设计。桌面端在「设置」中登录 Z.ai 账号（GLM Coding Plan）或按需配置模型服务；CLI 通过 drora login完成浏览器授权后即可提问。

自托管或私有接入时，可用 DRORA_BUILTIN_PROVIDER_CONFIG_FILE 指定本地 Provider 配置文件；服务地址等构建配置见仓库 .env.example 与 config/README.md。

任务与目标模式

桌面应用以任务组织日常工作：每个任务有独立的会话、工具执行与 Git 上下文。对多步骤的复杂目标，用 Goal 承载长程计划——Agent 持续规划、执行与验证，进度面板逐步打勾，你随时可以查看状态或补充指令。

  • 文件改动、终端执行与 Git 状态保持在同一任务上下文里。
  • Goal 面板展示目标描述、完成进度与 token 消耗。
  • 排队中的指令由运行时串行受理，不会丢失。

会话与编辑历史

每个会话都有完整的历史记录：消息、工具调用与文件编辑可回放查看；检查点让你回到任意一步之前的状态重新开始。中断的会话可以恢复，接着上次的进度继续。

手机远控

在桌面端开启远程访问后，用手机浏览器扫码或输入地址即可连接：桌面已有 Host 会被复用，同一会话运行时继续工作，不另起 Agent。局域网内可直连；跨网络时经 relay 云中继转发——relay 只做鉴权、配对、心跳与转发，不保存任务队列等业务状态。

连接断开后自动恢复，历史事件可回放；窗口关闭即停止服务，不会在后台滞留。

远程开发

除本机项目外，Drora 还可连接远程工作区（SSH/WSL）进行开发：会话在远程环境中执行，文件与终端操作发生在对应主机上。自托管 Web 后端时，可用 DRORA_SERVER_WORKSPACE指定工作区路径；详见仓库 README。

桌面宠物

夜墨、雪铃、杏桃三位猫娘实时呈现任务状态，陪伴你的每一次提交。宠物可拖动、可隐藏，不遮挡操作；在设置中即可选择角色或关闭。

皮肤中心

内置多套插画预设壁纸，支持自定义面板透明度与强调色，让工作台符合你的审美；所有预设都对齐设计规范，深浅细节都经过打磨。

使用统计

应用内置用量统计：查看各会话的 token 消耗、请求次数与工具调用分布，掌握成本与负载；统计数据基于本地会话记录生成。

技能与斜杠命令

技能（Skill）把可复用的工作流打包成一等公民：在会话中用 / 调用，参数通过模板展开；斜杠命令（Command）则提供轻量的提示词快捷方式。两者都可以在工作区或用户目录中自定义。

子智能体

主 Agent 可以把探索、检索与研究类工作委派给子智能体并行执行，只把结论带回主对话——在大型代码库中定位问题时尤其有用，能显著减少主上下文的占用。

MCP 与插件

通过 MCP（Model Context Protocol）接入外部工具服务：在工作区或全局配置 stdio/HTTP 服务器后，其工具自动进入 Agent 的工具面。插件则进一步打包技能、命令、Hooks 与 MCP 配置，可在应用内插件市场浏览安装。

Hooks

在会话与工具生命周期的关键节点注入自定义脚本：如 SessionStart、UserPromptSubmit、PreToolUse、PostToolUse 等。Hooks 可以补充上下文、校验或改写工具输入，并参与权限决策；工作区 Hook 按工作区身份与声明摘要审查信任。

自动化任务

定时任务按计划自动运行提示词；闲时任务把可延迟的工作排入空闲队列，在算力空闲时执行。自动化产生的运行与结果都有持久化记录，可在应用内查看。

命令行 CLI

发行包中的 drora-<os>-<arch> 是 Agent CLI 单文件可执行，须在终端中运行。它既是独立的终端 Agent，也与桌面端共享同一运行时：

drora # 进入终端交互界面（TUI） drora --web # 启动浏览器界面 drora -p "你的问题" # 单条提问（需先 login） drora login # 浏览器授权登录

Web 模式默认监听本机并自动打开浏览器；局域网访问可使用 --host 0.0.0.0，监听非本机地址时默认生成访问令牌：

drora --web --workspace /path/to/project --port 3030 --no-open

从源码构建

准备 Git、Node.js 24.14.0 和 pnpm 10.33.2 （版本以仓库 mise.toml 为准），在仓库根目录执行：

pnpm bootstrap # 安装依赖并准备桌面本地运行资源 pnpm dev:desktop # 启动 Electron 桌面应用（开发模式） pnpm dev:web # 启动 Web + 后端（localhost:5173 / :3030）

打包桌面安装包：

pnpm bundle:desktop -- --os win --arch x64 # 也可 --os mac|linux

仓库结构、配置项（如 DRORA_DATA_BASE_DIR 数据目录）与完整打包说明见 README。

常见问题

安装时提示「已损坏」或 SmartScreen 拦截？

社区构建未做签名：Windows 选择「更多信息 → 仍要运行」；macOS 在「系统设置 → 隐私与安全性」放行，或执行 sudo xattr -rd com.apple.quarantine /Applications/Drora.app。

有 Linux 桌面版吗？

暂未提供 Linux 预编译安装包；Linux 用户可先使用 CLI 单文件（ drora-linux-x64 ），或从源码 pnpm bundle:desktop -- --os linux自行构建。

如何更新？

桌面应用内置自动更新（latest 通道），也可以随时到 Releases 页下载新版本覆盖安装。

遇到问题如何反馈？

欢迎到 GitHub Issues 提交问题，或加入 README 中的 社区渠道 交流。
