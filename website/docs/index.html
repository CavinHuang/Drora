开始使用

欢迎使用 Drora

Drora 是一个开源的 AI 编程工作台：桌面应用、浏览器界面和终端 Agent 三种形态共享同一运行时。它把长上下文、长程任务与 Agentic 编程能力转化为稳定可用的桌面体验，覆盖规划、编码、审查与迭代的完整流程。

Drora 基于上游 ZCode 开源复刻并持续跟进，由社区维护。功能范围、维护规则与许可说明见 NOTICE.md。

核心能力

  • 任务与目标模式——用 Goal 承载长程目标，进度逐步打勾。
  • 手机远控——手机浏览器直连桌面已有 Host，断线可恢复回放。
  • 远程开发——连接 SSH/WSL 远程工作区开发。
  • 技能与斜杠命令、MCP 与插件——按需扩展 Agent 能力面。
  • 自动化任务——定时任务与闲时任务，计划内自动执行。
  • 桌面宠物——三只猫娘实时呈现任务状态，可拖动可隐藏。

快速开始

从 Releases下载桌面安装包或 CLI 单文件，登录模型账号后即可开始第一个任务；详见 安装与 连接模型。

pnpm bootstrap # 从源码开发：安装依赖并准备运行资源 pnpm dev:desktop # 启动 Electron 桌面应用（开发模式）
