核心功能

手机远控

手机远控把当前桌面窗口临时开放给手机访问：桌面端开启后，用手机扫码或打开链接即可连接。手机只是一层控制面——它不同步代码、也不新建环境，你发出的指令仍由桌面已有的 Host 执行，不另起 Agent。

适合什么场景

  • 离开电脑后，继续查看正在运行的任务与进度。
  • 在手机上给会话补充指令；运行中的输入由运行时排队串行受理，不会丢失。
  • 长任务、长目标跑到一半要出门，进展随时可查，回来无缝接续。

手机扫码连接

在桌面端侧边栏打开「移动端远程控制」：弹层展示二维码与链接，可以复制链接、刷新二维码，连接状态一目了然——等待手机连接、正在连接、手机已连接。注意手机连接的是整个桌面窗口：手机上看到的是这个窗口里已打开的工作区与任务，而不只是单个工作区。

连接方式有两种：

传输方式 说明
局域网 手机与电脑在同一局域网时直连，无需任何外部服务；二维码即配对入口，可在弹层一键刷新。
云中继 跨网络时经云中继转发，手机无需与电脑同网。中继只做鉴权、配对、心跳与转发，不保存任务队列等业务状态；可在设置中改用自建 relay 服务端地址。

手机端能做什么

任务首页

按工作区分组列出电脑上的工作区与任务，运行状态一眼可见，并可为已有工作区直接新建任务。

会话页

打开某个任务即是会话页：展示会话时间线与 Agent 的执行进度，可以直接输入后续指令继续推进。对应的任务正在被手机操作时，桌面任务列表会标出「手机正在操作此任务」。

命令在哪台机器上执行

手机端不创建任何执行环境。命令在哪台机器上执行，取决于该工作区在桌面端的连接类型：

工作区类型 代码和命令在哪执行
本地 你的电脑
SSH 对应的远程主机
WSL 对应的 WSL 发行版
Docker 对应的本机容器
Server 对应的 Drora 服务

停止与安全

二维码与链接就是配对凭据，请勿转发给不可信的人；不确定时可在弹层点击「刷新二维码」重新生成。关闭弹层并不会停止远控——不用时请点「停止」。

桌面应用退出或窗口关闭即停止远控服务，不会在后台滞留；下次启动时可自动恢复上一次的开启状态（手动停止过则不恢复）。远控期间请保持桌面端运行并联网。

常见问题

手机能新建任务或远程工作区吗？

可以为已有工作区新建任务；但新建远程连接（SSH / WSL / Docker / Server）需要在桌面端的连接向导里填写配置，手机端不做这件事。

手机能打开桌面端没开过的项目吗？

不能。手机上看到的是当前桌面窗口已打开或注册的工作区与任务，没有任意目录浏览权限。
