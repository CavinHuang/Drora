核心功能

远程开发

除本机项目外，Drora 还可以把工作区放到远程主机、WSL 发行版、本机容器或一台已运行的 Drora 服务上：连接成功后，文件读取、终端命令、Git 操作和 Agent 都在目标环境中执行，本地窗口只负责展示与交互。

连接方式

在窗口侧栏选择「远程连接」，按向导选择方式并填写配置：

方式 适用场景
SSH 连接远程 Linux 主机，把代码和运行环境放在开发机上
WSL 在 Windows 上通过 WSL 发行版打开 Linux 工作区
Docker 在本机容器中打开项目，获得干净、可随时重建的环境
Server 连接一台已运行的 Drora 服务，直接打开其工作区

连接步骤

向导按「选择方式 → 填写配置 → 连接 → 选择目录」进行；连接就绪后选择要在当前窗口打开的目录。

SSH

填写主机地址、端口和用户名，认证方式选择 密码 或 私钥 （私钥口令可选）。本机 SSH 配置里有别名时可直接选择，会自动填充主机、端口、用户名和私钥路径。

WSL

自动检测本机已安装的 WSL 发行版，选择后可指定运行命令的 Linux 用户，留空使用发行版默认用户。打开形如 \\wsl$\… 的 WSL 路径时，Drora 会建议改用 WSL 远程连接打开。

Docker

选择本机正在运行的容器，再选择容器内的目录。

远程资源准备

首次连接 SSH 环境时，Drora 会把运行所需的 Agent 资源准备到目标主机。资源下载方式二选一：

方式 说明
本地下载后上传 本机下载后经 SFTP 上传，服务器无法直连外网时也稳定可用
远端服务器下载 减少上传等待；要求服务器能访问 Drora CDN，并具备下载、解压和校验工具

同步到远程环境

连接远程环境后，可在设置中把本机已有的能力同步到目标环境，入口分别在 Skills、插件与 MCP 设置中；个人提供商配置与允许同步的账号凭据也会在连接存续期间自动传入目标环境，无需在远端重复登录。

自托管 Web 服务

命令行发行包可以把工作区暴露为浏览器可访问的 Web 服务，实现无桌面的远程开发：

drora --web # 启动 Web 界面 drora --web --workspace /path/to/project --port 3030 --no-open drora --web --host 0.0.0.0 # 允许局域网访问

Web 模式默认监听 127.0.0.1 并自动打开浏览器；监听非本机地址时默认生成访问令牌，请使用终端输出的带令牌链接，也可用 --token 指定令牌或 --no-token 关闭令牌认证。自托管后端的工作区路径可用 DRORA_SERVER_WORKSPACE 指定；直接部署通用 Web 服务时，用 DRORA_SERVER_AUTH_TOKEN 配置 API／WebSocket 认证。

注意事项

会话、文件与终端操作都发生在目标环境，执行身份是远端账号而不是本地用户；认证默认值因启动入口和监听地址而异，不要把开发服务或本机核心端口直接视为适合公开暴露的服务。需要在手机上继续桌面会话时，见 手机远控。
