技能与斜杠命令

技能（Skill）把可复用的工作说明打包成一等公民，让 Agent 在特定任务上按同一套标准执行；斜杠命令（Command）则提供轻量的提示词快捷方式。两者都可以放在工作区或用户目录中自定义。

技能（Skill）

一个技能就是目录下的一个 SKILL.md ：frontmatter 声明名称与触发时机，正文写给模型照做。会话中模型可按描述自行调用，也可以用 /skill 强制下一轮先加载指定技能：

/skill # 列出当前可发现的技能 /skill code-review # 强制加载 code-review 技能 /skill code-review 审查工作区改动 # 加载技能并附带任务

SKILL.md 结构

--- name: code-review description: 按团队规范审查当前变更 when_to_use: 用户要求审查代码、diff 或提交时使用 --- ## 审查步骤 1. 先读取相关变更，再逐条给出意见。 2. 按严重程度分组输出结论。
字段 说明
name 技能名称，调用与检索时使用；缺省时按目录名加载
description 一句话说明技能做什么，模型据此判断是否适用
when_to_use 可选；进一步说明触发场景，帮助模型在合适时机调用
带 frontmatter 的技能必须提供 name 与 description ，缺失或超长的描述会在扫描时报告诊断；正文没有大小写敏感的格式要求，普通 Markdown 即可。

技能存放位置

作用域 目录
项目 .drora/skills/ 与 .agents/skills/
用户 ~/.drora/skills/ 与 ~/.agents/skills/
插件 / 内置 随插件分发（以 插件名:技能名 引用），内置技能如 dynamic-workflows

项目作用域不只看当前目录：从工作目录向上到 Git 仓库根的每一层都会扫描，monorepo 的子包可以带自己的技能。同目录下 .drora 优先于 .agents ，两套目录可以并存。

/fork [latest|checkpointId]从工作区检查点派生新会话
/locale [auto|en-US|zh-CN] / /language查看或切换界面语言
/mcp [list|status|connect|disconnect]查看或管理已配置的 MCP 服务器

自定义命令

把常用提示词保存为 命令名.md 文件，放在项目 .drora/commands/ 或 .agents/commands/ （用户级为 ~/.drora/commands/ 与 ~/.agents/commands/ ），输入 / 时即可选用：

--- description: 生成符合约定的提交信息 argument-hint: [补充要求] --- 阅读当前暂存区的变更，生成一条符合 Conventional Commits 的提交信息。 补充要求：$ARGUMENTS
字段 说明
description 命令用途，显示在提示列表中
argument-hint 参数提示，如 [补充要求]
skills 执行前先加载指定的技能
disable-noninteractive 标记该命令仅限交互使用；带此标记的命令会被排除在应用的 / 命令面板目录之外
allowed-tools / model 已识别的元数据字段，可由 drora commands inspect 查看；运行时限制尚未接入

命令正文支持 $ARGUMENTS 整体替换与 $1 式位置参数；给出了参数却没有占位符时，参数会附加到提示词末尾。形如 !`cmd` 的动态 shell 展开暂不支持，会在展开时报错。

管理与检查

drora skills list # 列出当前可发现的技能 drora skills inspect <name> # 查看技能元数据与正文 drora commands list # 列出自定义命令 drora commands inspect <name> # 查看命令正文与参数展开

两条命令都支持 --json 输出结构化结果；把技能与命令同步到远程环境的方法见 远程开发。
