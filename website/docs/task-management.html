核心功能

任务与文件管理

随着任务越积越多，左侧边栏提供了几个高频管理能力：任务视图让你按分组、项目或时间线组织任务列表，命令中心在一个面板里快速触达操作、任务与文件，工作区文件树则让你不离开 Drora 就能浏览文件、查看变更并把文件引用进对话。

任务视图

侧栏顶部的视图菜单提供三种组织方式，可以随时切换：

  • 分组：按自定义分组归类任务，适合按主题或优先级整理。
  • 项目：任务跟着项目走，每个项目下平铺它的任务。
  • 时间线：按时间倒序排列，找最近做过的事最快。

视图旁还有几个常用入口：排序方式（按创建时间或更新时间）、任务搜索，以及归档——已完成等不再活跃的任务可移入归档列表，列表里随时可以恢复或删除；删除任务会连同它的会话快照与 checkpoint 一起清理。

任务分组

切换到分组视图后，可以把相关任务整理到自定义分组里：

  • 新建分组并命名；点击分组标题旁的颜色点，可在灰、红、橙、黄、绿、蓝、紫七种颜色中选择。
  • 随时重命名分组；右键分组可选择「取消分组并删除」——只删除分组本身，组内任务保留并移出分组。
  • 把任务拖进目标分组，或在任务上右键选择「移动到分组 / 移出分组 / 移动到顶部」。
  • 点击分组标题折叠单个分组，或用列表顶部按钮全部展开 / 收起。

命令中心

按 Ctrl/Command+K （或 Ctrl/Command+Shift+P ）打开命令中心，在一个面板里搜索操作、任务或文件：新建对话、打开文件夹、切换主题、打开设置等常用操作都能直接执行，不必到处找菜单。范围可按「全部 / 操作 / 任务 / 文件」筛选。全部快捷键见 快捷键表 。

工作区文件树

从工作区卡片的「显示文件树」入口切换到当前工作区的文件树，不离开任务就能浏览文件：

  • 按文件名或路径实时筛选，支持在设置中配置搜索忽略规则。
  • 「仅显示变更文件」一键过滤出有 Git 变更的文件，代码评审或提交前检查特别好用。
  • 单击文件在预览面板打开；右键菜单提供「添加到聊天」「复制路径」「在资源管理器中打开」等操作，本地 HTML 文件还能「用内置浏览器打开」。
  • 把文件添加到聊天，可以让 Agent 围绕该文件工作——「仅显示变更文件」加「添加到聊天」组合使用，能快速把本次改动喂给 Agent 做自查或生成提交说明。

附件也支持拖放与粘贴的方式加入输入区，详见 Drora Agent。

Git 图谱

工作区顶部的分支切换器旁可以打开 Git 图谱：一张只读的提交历史图，分支并排画出泳道，合并发生在哪里一目了然，适合理清「这个分支从哪儿分出去」「这两条线什么时候合的」。顶部会汇总提交数、泳道数、合并与引用数量。

它只负责看：切换分支走同一个分支切换器；如果切换时有未提交的改动，Drora 会提示先提交，也可以选择提交后自动继续切换。
