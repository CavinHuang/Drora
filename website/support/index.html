反馈渠道

渠道适合
GitHub IssuesBug 报告与功能请求（可追踪进展）

飞书社群 / Discord即时交流与快速答疑

反馈时请附上

  • Drora 版本号与安装方式；
  • 操作系统与 CPU 架构；
  • 复现步骤，以及预期与实际行为；
  • 相关日志片段（请先去除令牌、密钥等敏感信息）。

Issue 标题建议

用「[形态] 平台 + 一句话现象」的格式，便于检索，例如：

[桌面] macOS 15 Apple 芯片 启动后窗口白屏 [CLI] drora --web 指定端口被占用时未提示 [远控] 手机连接后桌面无响应
